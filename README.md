## 🛠️ Setup

1. Clone the repo:
   ```bash
   git clone https://github.com/skmdshadmansakib/App_demo.git
   cd App_demo
2. Install dependencies:

⊙ flutter pub get

3. Configure Firebase:

⊙ Add your google-services.json (Android) and/or GoogleService-Info.plist (iOS)

⊙ Ensure firebase_options.dart is generated using FlutterFire CLI

4. Run the app:

⊙ flutter run
